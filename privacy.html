Privacy Policy

Red Robin Backup is a private tool used by a single owner to store that owner's own backup files in that owner's own Google Drive.

What it accesses

It uses only the Google Drive "drive.file" permission, which lets it see and manage only the files it created itself. It cannot read any other file in the account.

What it stores

Backup files are encrypted before they are uploaded. The sign-in token that lets the tool upload is stored encrypted on the owner's own server.

Sharing

No data is shared with, sold to, or accessed by anyone else. No data is used for advertising or analytics.

Removing access

The owner can revoke access at any time from the Google Account security page, and can delete the uploaded files from Drive.
